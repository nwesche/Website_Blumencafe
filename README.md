# Blumencafé mit Take-away & Anlässen

Konzept-Website (Mobile, Tablet, Desktop).

**Web-Vorschau:** https://nwesche.github.io/Website_Blumencafe/ – reine Ansicht; Bestellungen, Zahlung und Dashboard funktionieren nur mit dem lokalen Server.

## Lokal starten (voller Funktionsumfang)

Voraussetzung: Python 3. Doppelklick auf `start_server.bat` oder:

```
python server.py
```

Dann http://localhost:8080/ öffnen. Einstellungen (PIN, Stripe, E-Mail) in `config.json`.
